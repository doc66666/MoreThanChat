# MoreThanChat
一切皆插件的聊天应用，或许你的企鹅已经过时了！

最新正式版：[v0.4.1 下载与发行说明](https://github.com/doc66666/MoreThanChat/releases/tag/v0.4.1)。修复界面插件下的聊天定位、返回最新消息和已读判断，调整内置助手的聊天读写能力说明及旧对话上下文处理。包含 Windows 客户端安装器／ZIP，以及内含运行环境、一键启动和管理 CLI 的 Windows、Linux 中心服务器包。见[服务器快速入门](docs/central-server-quickstart.md)。后续正式发布均同时提供客户端和中心服务器。

当前 v0.2.0 支持同一份 AI 可执行界面插件本机使用、向群申请由管理员批准分发，以及向好友申请由对方同意后分发。成员各自选择载入，通过中心事件接口同步；可改造整个界面，不限固定插槽。见 [共享插件 SDK 与验收](docs/plugin-runtime.md#2026-10-14同一可执行包的本机群聊私聊闭环)，回归命令 `pnpm verify:shared-plugins`。旧 v0.1.0 内测标签保持不变。

## 首个正式发行版：v0.2.0（Windows x64）

在 [GitHub Releases](https://github.com/doc66666/MoreThanChat/releases/tag/v0.2.0) 下载安装器或 ZIP，手动安装更新；不内置自动更新。发行说明、服务端部署和已知边界见 [v0.2.0 发行说明](docs/releases/v0.2.0.md)。应用版本为 0.2.0，插件契约仍兼容 `engine.moreThanChat: ^0.1.0`，两者独立演进。

正常启动仅自动加载中心通信核心，不预装或启用问候、工作区卡片、时间工具和群游戏演示。AI 默认等待配置真实 API，不以模拟回复代替接入。用户主动安装的插件和既有配置不会被清除；开发验收可通过 `MTC_QA_MODE=1` 显式启用演示环境，不要将该环境变量用于交付启动脚本。

发行包仅收集桌面运行时、依赖和独立 Host，不包含验收账号、数据库、DS 草稿或密钥。测试证据留在隔离用户目录。提供未签名 NSIS 安装器与 ZIP；默认中心为 localhost，公网服务需自行部署。

历史真实 DS 群插件验收使用 JSON 状态机，见 [内测记录](docs/ds-group-plugin-acceptance-2026-10-13.md)。此版新增可执行 JS 插件的本机、群聊、私聊完整流程，自动验收使用本地确定性模型响应测试工具调用，不能视为真实 DeepSeek 模型生成质量保证。更新、停用、断线补投和换人对局已有桌面回归覆盖；游戏规则仍由插件作者实现。

当前阶段：Windows 聊天、中心服务与插件扩展的首个正式发行版。已有全局签名身份、好友/群聊、离线暂存与收件确认清除、群与私聊插件审批及同步。默认开发服务为 `http://localhost:8787`，可在设置切换同一程序运行的私服。AI 聊天、声明式与可执行插件草稿创作均保留。

中心服务已有独立发布目录和 Linux 单机部署模板，支持同一数据目录防重复启动、限时正常停机、崩溃后恢复未送达队列、健康探针和受管理员认证保护的聚合状态查询。好友／群／插件审批与通知入队采用同一事务；满队列不会阻挡有效 ACK 释放待收正文。仍只暂存未送达内容，不开启长期正文归档。Windows 与本机 Linux 的进程级故障恢复已验收；公网 TLS 部署、容量压测、完整限流和集群尚未验收，具体步骤与边界见[中心服务部署文档](docs/central-and-plugin-stage-2026-10-11.md#中心服务器部署与故障恢复2026-10-13-后续阶段)。

流量保护已进一步按身份分开限制发送、插件事件、查询、收件和 ACK，普通请求不能用尽控制请求的预留名额；同一 UID 的多个设备／会话共享额度。上传读取并发和各接口请求体也有边界，429 不会把客户端持久发送队列清掉。`pnpm verify:central-load` 可运行 64 轮真实群消息、附件、离线设备及中途重启验收；这仍是短时负载基线，不是生产容量或长期在线承诺。

大响应增加分块发送、等待网络缓冲释放、全服缓冲预算和每身份并发限制；停止读取的客户端在响应期限后被断开，未 ACK 内容仍可补投。管理员状态可查看大响应占用、超时次数和进程内存聚合。`pnpm verify:central-soak` 会先验证真实慢收件超时，再在同一服务进程中持续收发三分钟；分钟级观察不等于小时／天级稳定性保证。

中心数据库查询现在复用有上限的预编译语句；游标使用期间独占，失败语句淘汰，不缓存查询结果。管理员可查看缓存数量、编译次数和命中次数。`pnpm verify:central-memory` 运行十分钟临时负载，并在全部收发结束后通过测试专用 IPC 对比一次垃圾回收前后的内存；正常服务不开放这个诊断通道，也不强制垃圾回收。

用户在设置中配置 API、模型和 Key，在 More AI 会话中描述需要的插件，再到插件面板确认安装。当前支持固定文本、输入框文本追加，以及大写/小写/首尾空白转换。模型读取实际契约和样例，通过工具创建、校验与修订；用户掌握安装和更新决定。插件启停与版本会保存，失败更新可恢复旧版并继续提交修订。

聊天内核已接入 SQLite 事务存储，自动迁移旧会话并保留备份；退出前确认保存。AI 回复支持 Markdown、代码块、表格、失败/取消后重新生成，以及接口报告的 Token 用量。重试保留原问题和失败记录，不重复发送问题到会话列表。

人与人聊天已增加本机持久发送队列，离线时可排队，重连所属服务器后自动补发，使用原消息 ID 防重。支持送达/已读回执、按阅读位置处理未读、每会话草稿恢复、聊天记录搜索与定位、消息复制、置顶和免打扰。每个好友／群固定一个入口，不提供归档；删除好友、退出或解散群后移除关系入口，但历史记录仍留在本机，可通过搜索查看。好友申请可取消或拒绝，群可改名、邀请和移出成员、转让管理员。

插件可以注册侧栏、导航、消息区域、详情、输入区或浮层，也预留了可信插件替换输入区的能力。群成员可申请接龙、井字棋和通用同步通道，管理员批准后向同服群成员分发。加号支持文件与表情，右侧按住说话，文件和语音在中心会话内发送。

客户端提供暖白陶橙的白天模式、Tokyo Night Storm 夜间模式，以及跟随系统；设置中选择外观，左下方太阳/月亮按钮快速切换。会记住每个用户的选择，并统一聊天、插件、设置与窗口标题栏的配色。

设置 → 通知与后台：支持窗口不在前台时的新消息系统通知，默认不显示正文、不播放声音；可分别开启预览和声音。免打扰会话不提醒，同一会话的连续消息合并提醒，点击通知打开对应会话。可选“关闭窗口后继续接收”，或手动收起到托盘；托盘可重新打开和彻底退出。默认关闭窗口仍然退出，保存失败时保持窗口可见。真正退出、系统休眠或断网期间不承诺实时通知，未送达消息由中心保留，重连后补投。

Key 由 Electron Main 的系统加密服务保存，Host 通过私有 RPC 获取运行时凭据；不使用明文文件回退。远程分发支持声明式包和可执行界面包。可执行插件属于受信任客户端代码，不是恶意代码安全沙箱；只安装你愿意运行的插件。Android、端到端加密与代码签名安装器尚未交付。

历史记录通过 SQLite 游标真正分页加载，默认每会话最近 50 条，支持加载更早／较新记录、搜索定位和回到最新消息。已取消整个聊天历史的 8 MiB 上限；分页保存是增量写入，不会删除未加载的历史。搜索使用本机 FTS5 trigram 索引筛选至少三字符的子串，短关键词走参数化子串查询。仍保留单页／单记录的安全边界。

新消息支持引用回复、定位来源、同服单条转发，以及本人两分钟内撤回。引用随输入草稿切换和重启恢复；转发复制文字或原附件，以独立新消息发送。中心保留来源与路由校验所需的 ID、摘要哈希及收件人元数据，不保留全部目标设备均已确认的正文。撤回通知离线暂存，客户端落盘后再确认；引用摘要也会被清除，但已转发、下载或复制的独立副本不保证删除。首次升级前已经送达且正文已清除的旧消息无法补生成可信来源校验，仍可搜索和复制。

联系人面板内的“身份与设备”支持密码加密身份备份、导入与本机身份切换。不同身份的聊天、插件、模型设置和界面存储隔离，导入不覆盖原空间。用同一份备份在另一台电脑导入、连接原服务器，即可恢复好友和群关系；登记后的新消息、自己的发送内容、已读与撤回按设备同步。中心为每个身份最多登记 8 台设备，离线设备仍有独立待收记录，全部目标设备确认后清除暂存正文；“已送达/已读”人数按用户统计，该用户任一设备确认即可计入。可移除不用的设备释放待收记录。身份备份不包含聊天历史、插件、API 密钥或设备 ID，不能找回中心已清除的历史。旧客户端在同身份启用多设备后需要升级。

设置 → 聊天记录与迁移：支持手动导出、合并恢复本身份的加密 `.mtchistory` 备份，包含完整本机聊天历史及消息引用的文件／语音附件，不限于当前加载的最近 50 条。换机时先导入原 `.mtcidentity` 并切换到同一 UID，再恢复历史；身份备份和历史备份是两份独立文件，请分别保管密码。历史文件经密码加密和原身份签名校验后才允许合并，不能用于导入他人的身份或证明消息经过服务器认证。

恢复保留本机已有记录、好友／群关系和设置；相同消息不重复导入，撤回状态优先。旧发送队列、已读回执队列不重放，也不安装插件或导入 API 密钥。只从备份新增的网络会话先作为只读历史，需要连接原中心并由服务器确认当前关系后才能继续聊天。备份上限为 1 GiB 编码内容、100 万条历史记录，单附件仍为 5 MiB；它不是定时备份、云同步或 Android 迁移服务。错误密码、签名错误及身份冲突不会合并消息；附件准备后合并失败可能留下未引用的新附件，程序不因此删除原有文件。若成功后提示临时数据清理未完成，已完成的备份／恢复仍有效，但需要保护可能残留的明文暂存数据。迁移功能尚未在公网真实服务器或 Android 上验收。

## 当前可运行原型

仓库已经包含一个 Electron 桌面聊天原型，支持会话切换、搜索、新建会话、发送消息、本地持久化和插件启停。两个可信 UI 插件提供本地演示传输与快捷问候；独立 PC Host 运行时间工具插件，支持面板启停、结果写入输入框与崩溃后恢复启停选择。Renderer 保持沙箱与最小 Preload API。

```powershell
pnpm install
pnpm central:dev
# 另一个终端打开两个独立用户端：
pnpm demo:clients
# 常规单客户端开发：pnpm dev
```

验证：

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm verify:plugin-ui
pnpm verify:host
pnpm verify:protocol
pnpm verify:ai-ui
pnpm verify:chat-ui
pnpm verify:central-ui
pnpm verify:background-ui
pnpm verify:appearance-ui
pnpm central:package
pnpm verify:central-ops
pnpm verify:central-load
pnpm verify:central-soak
pnpm verify:central-memory
pnpm package:dir
```

`pnpm package:dir` 在当前系统生成 unpacked 目录，并检查 Host 依赖位于 `resources/pc-host`、不在 `app.asar` 里。Linux 上的结果不是 Windows 安装包验收。

Windows CI 验证目录版中的聊天/插件/加密凭据恢复，成功后上传 `MoreThanChat-windows-x64` 验收产物。正式下载使用 Releases 中的安装器或 ZIP；ZIP 解压后运行 `MoreThanChat.exe`，需要保留整个目录。当前未做代码签名。

真实 API 测试需要交互输入 Key，不使用命令参数或提交到 Git：

```powershell
pnpm test:live-ai
# Windows 桌面真实模型验收：
pnpm build
node scripts/verify-ai-ui.mjs --live
```
