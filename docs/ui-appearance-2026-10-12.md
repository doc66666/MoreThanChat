# 客户端外观与交互（2026-10-12）

默认使用暖白主题：纸色背景、米灰面板和陶橙操作色。夜间使用 Tokyo Night Storm 的蓝灰背景、淡蓝文字与柔蓝强调色，基础色取自 [Tokyo Night Storm 官方色板](https://github.com/folke/tokyonight.nvim/blob/main/lua/tokyonight/colors/storm.lua)。区域边界由相邻底色与低对比细线共同表达，聊天气泡避免大面积高饱和色。

设置面板提供暖白、夜色、跟随系统三个选项。左下方的太阳/月亮按钮可直接切换白天与夜间。选择保存在当前用户数据目录的浏览器本地存储中，重启后恢复；跟随系统时会实时响应系统外观变化。Windows 窗口控制区颜色同步，首次显示窗口等待页面就绪。

按钮、输入框、会话列表、插件卡片、Markdown、附件菜单、设置及群插件共享颜色变量。插件界面可使用 `--canvas`、`--surface`、`--panel`、`--text`、`--text-secondary`、`--muted`、`--border`、`--accent`、`--accent-soft` 等变量适应主题。历史 `--purple` 和 `--purple-soft` 作为兼容别名保留。插件自行写死的颜色需由插件作者适配。

交互反馈包含轻微悬停和按压、清晰的键盘焦点、短距离抽屉/菜单过渡和新消息进入动画。系统启用减少动态效果时关闭这些动效。输入框随内容增高，中文输入法选词时按 Enter 不发送；附件菜单支持点外关闭和 Esc 收起，插入表情后焦点回到输入框。关闭详情面板后聊天区域填满空出的空间。

运行 `pnpm verify:appearance-ui` 验证两套主题、重启恢复、跟随系统、快速切换、菜单与输入法交互、减少动态效果及 900/1024 像素布局。验收对正文、按钮和主要次要文字检查实际渲染的对比度，截图保存到 `.artifacts/appearance-*.png`。CI 对开发版和 Windows 目录版各执行一次。
