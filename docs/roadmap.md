# MoreThanChat 开发路线图

原则：先证明插件内核和回滚，再做完整聊天 UI；先让 AI 在受限范围内稳定写插件，再逐步开放能力。

## 当前待办与验收边界（2026-10-13）

- [ ] 真实 DeepSeek 发行版用户闭环：群成员让 AI 在用户级目录创建井字棋插件 → 本人提交 → 管理员审批 → 成员收到插件 → 成员自主选择本机载入 → 多端实时对局、停用及更新重确认。按用户要求暂缓；等待用户明确空出电脑后再做桌面操作。本轮不调用真实 AI、不消耗 API 额度，不把模拟模型或协议测试算作这项验收通过。此前尝试见 [真实 DS 验收记录](ds-group-plugin-acceptance-2026-10-13.md)。
- [ ] 桌面人工体验回归：白天／夜间、小窗口、中文输入法、文件选择后切换会话、实际麦克风权限与录音取消、插件申请及本机载入；搜索清空／切换范围／定位、附件预览重试与另存为取消、抽屉键盘焦点、断线重连表单及群管理。代码和无界面测试先行，尚未进行本轮实际桌面验收。

输入与插件交互阶段：附件准备与发送等待提示、光标处表情插入、输入法候选回车保护、长文件名布局、可关闭的中性通知；录音增加计时、键盘操作和设备错误提示，取消／失焦／卸载会作废延迟结果并释放麦克风，语音提交失败保留已准备附件，慢发送不会清空后来修改的草稿。插件位置改为中文、显示三步申请流程和不可提交原因、防重复点击、折叠审批记录，并保留本机授权／同步错误供重试。新增无桌面测试覆盖这些边界；视觉与真实设备表现仍以上述待办验收为准。

输入与插件交互阶段验证：新增 18 项无界面单测；`pnpm test` 共 392 项通过、2 项平台条件跳过；`pnpm typecheck`、`pnpm package:dir` 通过，Windows 目录版已更新但未启动。目录版依赖布局校验不等于桌面人工验收，未运行任何 computer-use 或真实 AI 请求。

搜索、附件与联系人补漏阶段：搜索输入清空立即结束加载，旧查询／旧范围的迟到结果与错误作废；支持重试、结果数量和所属会话说明。附件分离预览与保存状态，支持加载／解码失败重试，卸载释放预览 URL；保存 IPC 明确区分 saved／cancelled，不把取消文件选择误报为保存成功。联系人界面校验 UID、自己／已有好友／待处理申请，建群限制到本服现有好友、最多邀请 19 人；断线禁用管理与审批操作，单面板防重复请求，同服自动重连保留未提交表单，切换服务器清除旧服务器选择。群管理增加邀请空状态、人数上限和管理员转让／解散后果；搜索与联系人抽屉增加键盘焦点约束及返回入口。新增 22 项控制器、IPC 和无窗口 React 静态结构测试，全套 414 项通过、2 项平台条件跳过，类型检查通过。静态结构测试不等于真实点击、视觉或系统文件选择器验收。

该补漏阶段的 Windows 目录版已重新构建，Host 依赖布局校验通过；没有启动客户端、使用 computer-use 或请求真实 AI。上述真实用户闭环和桌面人工体验仍为未完成待办。

设置与身份补漏阶段：通知设置／历史备份状态读取增加原地重试，推送事件优先于在途旧查询，关闭面板和 StrictMode 重挂载会作废旧订阅结果。设置抽屉改为非表单容器，仅 AI 设置拥有自己的保存表单；历史备份使用独立标准表单，取消按钮不提交，输入法候选 Enter 不提交。模型保存、通知配置和身份操作补同步防重复锁；模型字段保存时锁定，删除 API 密钥与退出应用增加说明和确认。身份备份取消、导入取消、身份切换取消和移除设备取消分别反馈；已完成导入／移除但列表读取失败时，不误报成整个操作失败。密码前置校验与主进程边界一致。新增 19 项状态控制、表单结构和 IPC 测试；全套 433 项通过、2 项平台条件跳过，类型检查通过。

- [ ] 设置与身份桌面验收：键盘 Enter／Tab／取消、删除密钥确认、退出确认、原生身份切换与设备移除取消、状态读取故障后的重试。无窗口测试不替代这些实际交互验收；真实 DS 闭环继续延后。

设置与身份阶段的 Windows 目录版构建、Host 独立依赖布局校验均通过，未启动客户端；没有调用真实 AI 或使用 computer-use。

## Phase 0：架构钉子（1 周）

当前进度（2026-10-10）：已完成 Windows AI 聊天与受限 AI 插件创作 MVP。可信 `pc-ui` 插件生命周期、manifest 校验、v1 Host 协议与 JSON Schema、Electron Main↔utility process 监督及崩溃恢复均已落地。Cordis Core 固定为 `3.18.1`，独立 `pc-host` 时间工具插件通过适配层运行。

模型已支持兼容 API 的流式回复、取消和失败处理，并已用真实 DeepSeek 验证插件生成、修订、执行及恢复。Key 通过 Electron Main 的 `safeStorage` 加密，Host 通过私有 RPC 获取运行时凭据；不再使用明文凭据文件。聊天模型可读取契约、创建、校验、诊断和修订受限 JSON 插件，用户确认后立即启用。支持固定文本、输入追加和 uppercase/lowercase/trim 转换。更新保存不可变版本，失败回滚后可以继续修订；取消确认不会安装或替换，停用状态在更新及重启后保留。

本机 Windows 目录版已完成聊天内生成、确认安装、执行、修订、确认更新和加密凭据恢复的模拟服务验收。CI 对 Windows/Linux 做锁定安装、类型检查、单测、构建及协议验证，并在 Windows 验证目录版、上传可分发目录。Host 与生产依赖位于 `resources/pc-host`，在 `app.asar` 之外。详情见 [阶段验收记录](stage-acceptance-2026-10-10.md)。

本阶段提前实现了 Phase 4 的受限子集；完整路线图仍保留。后续的“可用聊天内核”阶段已接入 SQLite 事务投影和诊断日志、Markdown、AI 回复重试与 Token 元数据，详见 [聊天内核阶段](chat-core-stage-2026-10-10.md)。费用金额、动态服务依赖、签名插件包及完整更新事务、任意逻辑插件、人与人的在线聊天传输和 Android Host 均待后续。目录版是未签名内测分发，正式安装器另列发布阶段。

交付：

- pnpm monorepo、统一 TypeScript/ESLint/Vitest 配置；
- `packages/protocol`：传输无关的命令/事件 envelope、schema 生成和 Electron IPC 绑定；
- `packages/plugin-manifest`：manifest 校验与权限词汇；
- `packages/runtime-cordis`：只暴露我们自己的 `Runtime` 接口；
- 生命周期契约测试：加载、依赖等待、dispose 清理、失败回滚、重复启停；
- 最小 Electron main/renderer/utility-process 三层骨架；
- preload 最小权限桥、类型化 IPC 握手、utility process 崩溃重启；
- 锁定 Electron、Cordis 与 SQLite 依赖版本，记录升级基线。

验收：同一个示例插件可以启动、贡献一个 service、卸载后零残留；utility process 被杀后 main 能拉起新实例，Renderer 重连并显示明确状态；Renderer 无法直接访问 Node API。

## Phase 1：可用聊天内核（2–3 周）

当前核心能力已完成内测实现：会话迁移/事务存储、Markdown、取消与重新生成、Token 用量、加密凭据。日志是有界诊断日志，尚不是用于跨设备同步的完整事件源；费用金额、消息分页/全文检索及真实在线传输继续迭代。

交付：

- SQLite 事件存储和会话投影；
- OpenAI-compatible `ModelProvider`，支持 DeepSeek base URL/API key；
- 流式文本、取消、错误重试、token/费用元数据；
- 基础会话列表、对话流、Markdown、设置页；
- OS 凭据库保存密钥，诊断日志脱敏；运行时凭据不进入聊天历史备份。用户主动写入消息正文的秘密仍属于聊天内容，需由加密备份和密码保管保护，不能承诺自动脱敏。

验收：重启后可恢复会话；流中断不会留下伪完成消息；API key 不出现在数据库、日志或前端状态中。

## Phase 2：静态插件 SDK（2 周）

交付：

验收：不改核心代码即可安装三个示例；任意启停 100 次无重复监听器、重复 UI 和句柄泄漏。

## Phase 3：产品级热更新（2 周）

交付：

- stage/activate/health-check/commit/rollback 事务；
- 插件数据命名空间和迁移事务；
- worker/utility process 崩溃隔离；
- HMR/回滚故障注入测试。

验收：在 activate、迁移、UI 装载和健康检查四个阶段分别注入失败，均恢复旧版本且无数据半迁移。

## Phase 4：AI 插件作者（3 周）

## Phase 5：聊天平台能力（按产品优先级）

2026-10-13 数据库复用与内存诊断阶段：中心查询增加 128 条上限的预编译语句缓存，游标占用期间独占、异常语句淘汰且不自动重放写入；参数重绑和实时查询结果保持隔离。管理员获得编译／命中／活跃语句计数，新增十分钟负载与测试专用的结束后 GC 对照。正常服务不启用强制 GC 或诊断入口。实际测量结果见中心服务阶段文档，小时／天级稳定性、多用户规模及元数据长期增长仍待验证。

2026-10-13 慢收件与持续运行阶段：大响应增加 64 MiB 全服序列化载荷预算、单 UID 两个发送响应上限、分块背压和 30 秒绝对发送期限；超时／断开回收预算，不将 HTTP 完成当成收件 ACK。管理状态增加仅管理员可读的响应占用和 RSS／heap／external 聚合。真实暂停读取、重新补投、附件哈希、停机恢复和同进程分钟级循环进入验收；脚本可延长到一小时，但实际通过时长以阶段记录为准。后续优先做小时级 soak、低速网络附件续传、元数据增长与发布链路验收；没有把有界大响应载荷当作整个进程内存硬上限。

2026-10-13 流量保护阶段：已按已认证 UID 分离发送、插件事件、查询、收件、确认和重新登录额度；认证入口另有全服预算，不信任代理头作为身份。全服 256 个处理请求中保留 32 个控制名额，消息请求体读取并发限制为 4 个，普通／控制上传分别限制同身份占用。新增真实 HTTP 过载与客户端 429 持久重试测试；Windows／Linux 的真实群消息、附件、离线设备及中途强杀补投进入可重复负载验收脚本。此阶段是短时负载与资源保护基线，下一步仍需小时级持续运行、慢收件客户端内存／响应背压测试、元数据增长策略及公网发布验收，不声称生产规模或完整抗滥用已经解决。

2026-10-13 中心服务运营阶段：已补单数据目录进程锁、初始化失败清理、限时正常停机、健康／就绪探针、脱敏启动日志与管理员聚合状态 CLI。独立发布包包含配置、systemd 和 Caddy 模板，Windows 与本机 Linux 均验证进程强制结束后的重启、离线群消息／附件补投、逐设备 ACK 与不复活已清除正文。好友／群／插件操作与通知入队事务化，管理员名单变更不被启动种子覆盖；新业务队列预算不会卡住有效 ACK／首次已读控制通知。仅是单机可靠性基线，不是完整公网运维保证。下一阶段优先做容量与长期运行测试、按身份的细粒度限流及发布链路验证；公网真实部署、实时音视频、Android 与任意可执行插件沙箱仍待后续。

2026-10-13 本机历史迁移：已接入设置中的手动加密备份／合并恢复。SQLite 一致性快照遍历全部会话、消息和撤回记录，并打包所有被消息引用的附件；密码加密之外还使用原身份签名绑定内容，恢复仅限当前同一 UID，换机需先恢复身份。导入采用独立暂存库、严格记录验证和单事务合并，已有消息及关系／设置优先，撤回不被旧正文复活，不导入或重放发送／已读队列。只从备份新增的网络会话保持只读，等待原中心确认当前关系；界面清空旧分页游标并重新加载历史。上限为 1 GiB 编码内容、100 万条历史记录、单附件 5 MiB。附件先校验发布再合并；中途失败可能留下未引用的新附件，但不删除旧数据。当前为本机手动迁移，不包括定时备份、云端同步、跨身份合并、插件／草稿迁移；尚未在公网真实服务器或 Android 上验收。后续优先继续加强服务运营可靠性、恢复故障诊断和发布链路，再规划实时音视频与 Android。

2026-10-13 通知阶段：桌面通知与后台阶段已实现。支持私密/静音默认通知、连续消息合并、免打扰与撤回清理、点击返回会话、可选关窗到托盘、显式退出及按身份持久设置。真实 Electron 双端验收覆盖隐藏窗口接收/ACK、不提前已读、重启恢复，以及通知/保存失败；Windows 目录版同步验收。其后接入本机历史迁移（见上）。Android 系统推送、开机自启和退出后的常驻服务尚未实现。

2026-10-13 身份阶段：身份加密备份/导入、隔离的本机身份空间和已登记设备的新消息同步已落地。设备独立 ACK、发送者其他设备同步、跨设备已读与撤回、离线/重启补投和设备移除进入验收。最多 8 台设备；新设备只从登记后接收新消息，旧历史现在可通过上面的手动备份迁移，仍无跨设备插件／草稿同步。系统通知和本机历史迁移的后续进度见上。

2026-10-12：已补齐持久发送队列、送达/已读、焦点与滚动位置对应的未读、会话草稿、置顶/免打扰、本机搜索/定位/复制，以及好友申请管理、群成员管理和管理员转让。按产品要求移除了归档：好友/群固定关系入口，删除好友或退出/解散群后保留可搜索的本机历史。SQLite 游标分页、增量写入、FTS5 trigram 检索和大于 8 MiB 的历史保存也已接入；群消息部分送达后服务器重启的独立 ACK 流程已补测。消息引用/撤回/转发阶段现已完成：来源哈希校验、引用草稿与定位、文字/附件独立转发、两分钟撤回、离线持久通知和防止迟到正文复活均已接入。下一优先级是身份备份/导入与多设备同步，之后是系统通知和实时音视频。

2026-10-11 首版已接入：公共黑名单/私服白名单、全局签名身份、同服好友与群、持久离线中继及按收件人 ACK 清除、群插件审批分发与同步通道。默认开发服务器为 localhost。UI 插槽扩展到输入框之外，文件/表情/按住语音已进入正常聊天输入区。范围、部署与测试见 [中心服务阶段](central-and-plugin-stage-2026-10-11.md)。任意可执行包沙箱、端到端加密、运营级限流/集群、Android 继续作为后续工作。
