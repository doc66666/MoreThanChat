# MoreThanChat v0.4.0

这一版把聊天读写接口和中心服务器的安装管理一起整理好了。

## 聊天与内置助手

- 内置助手可以按要求读取好友、群聊记录及附件，并向指定会话发送消息。
- 修复切换服务器、断线重连和发送重试时的会话隔离与重复投递问题。
- 发送结果不明时保留原消息 ID，便于核对记录和重试；失败记录会返回具体原因。
- 修复附件读取的文件名、类型混用问题，以及文本分页截断表情字符的问题。
- 修复工具结果脱敏破坏 JSON、连续失败后提示不对应当前任务的问题。
- 调整聊天进入位置、未读定位和底部已读判断；后台发送不再把正在翻阅的记录拉到底部。
- 完善昵称修改指引，并同步会话入口、标题和消息中的显示。

## 中心服务器

- 发布页新增 Windows、Linux 中心服务器包，内含运行环境，解压即可启动。
- 提供启动脚本、交互配置及管理 CLI，支持启动、停止、重启、状态查询和日志查看。
- 支持在线切换黑名单／白名单模式，以及名单的查询、添加和移除。
- 模式和名单修改立即生效、重启后保留，不影响已有好友、群聊和待投递消息。
- 后续正式版同步提供客户端和中心服务器下载，统一附带 SHA-256 校验文件。

## 下载与使用

- **Windows 客户端**：`MoreThanChat-0.4.0-x64-setup.exe` 或 `MoreThanChat-0.4.0-win.zip`。
- **Windows 中心服务器**：`MoreThanChat-central-server-0.4.0-windows-x64.zip`，解压运行 `start.cmd`。
- **Linux 中心服务器**：`MoreThanChat-central-server-0.4.0-linux-x64.tar.gz`，解压运行 `./start.sh`。

中心服务器默认端口为 **8787**，首次直接启动采用白名单模式。开放测试可运行 `mtc-server mode public`；Windows 使用 `mtc-server.cmd`，Linux 使用 `./mtc-server.sh`。配置和管理说明见包内 `README.md`，或[服务器快速入门](https://github.com/doc66666/MoreThanChat/blob/v0.4.0/docs/central-server-quickstart.md)。

更新已有服务器时保留原配置、管理员凭据和数据目录。客户端与服务器均由用户手动下载安装更新。
