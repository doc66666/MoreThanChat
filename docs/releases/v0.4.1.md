# MoreThanChat v0.4.1

这次主要修复聊天窗口定位和界面插件之间的冲突，并调整内置助手的聊天读写能力说明。

## 聊天窗口

- 修复启用浮窗等界面插件后，进入会话停在最早消息、“回到最新消息”按钮无效的问题。
- 保留默认聊天界面的插件不再阻止滚动和已读更新；聊天被替换或遮挡时，不会自动标为已读。
- 修复插件热更新、停用后，恢复的消息区域未重新绑定滚动监听的问题。
- 加载历史记录期间也能返回最新消息，迟到的历史请求不会再次改变当前定位。
- 从通知进入已经打开的会话时，退出历史浏览并定位到最新消息。
- 避免快速切换会话或定位历史时，上一操作的延迟滚动影响新位置。

## 内置助手

- 每次请求明确提供当前可用工具，区分直接读取、发送聊天消息与插件创作流程。
- 修正能力说明中容易将插件输入框操作与聊天发送接口混淆的表述。按用户要求向指定好友或群聊发送消息，不需要创建插件，也不依赖打开目标聊天窗口。
- 旧助手回复中的工具清单和权限判断标记为历史背景，避免将旧版的“没有读取或发送工具”继续当作当前能力边界；本机原有聊天记录保持不变。

## 下载与更新

- Windows 客户端安装器：`MoreThanChat-0.4.1-x64-setup.exe`
- Windows 客户端压缩包：`MoreThanChat-0.4.1-win.zip`
- Windows 中心服务器：`MoreThanChat-central-server-0.4.1-windows-x64.zip`
- Linux 中心服务器：`MoreThanChat-central-server-0.4.1-linux-x64.tar.gz`

中心服务器包包含运行环境、一键启动脚本和管理 CLI。Windows 运行 `start.cmd`，Linux 运行 `./start.sh`；配置、日志和黑白名单管理见包内说明或[服务器快速入门](https://github.com/doc66666/MoreThanChat/blob/v0.4.1/docs/central-server-quickstart.md)。

更新前完全退出旧客户端，再安装新版或解压到新目录运行，无需删除聊天记录、配置或已安装插件。更新已有中心服务器时，保留原配置、管理员凭据和数据目录。发布文件统一附带 `SHA256SUMS.txt`。
