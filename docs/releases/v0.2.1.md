# MoreThanChat v0.2.1 — AI 插件创作修复

此版修复 v0.2.0 中 AI 误用旧声明式插件限制、嵌套 JSON 容易出错和工具修订过早中断的问题。旧版本与下载保留，不覆盖。

## 修复内容

- 新插件默认走可执行 JavaScript；默认系统提示词和 SDK 查询不再混入旧状态机的完整说明。旧插件仍可运行、修订，需要时通过 `inspect_drafts({format:"legacy"})` 获取旧契约。
- `create_draft` 新增直接传 `manifest` 对象与 `code` 字符串的方式，Host 负责 JSON 包装。保留旧 `manifestJson/source` 接口，但不允许混用两种输入。
- 明确 15×15 五子棋可以使用 225 格普通 JavaScript 数组，旧状态机的数组、网格和状态大小限制不是可执行插件的限制。
- 草稿增加原生 ES module 语法与默认导出检查；只解析、不执行。错误直接反馈到模型和进度信息，并返回已保存的修订号与修复提示。
- 工具创作预算由 6 轮调整为 12 轮，另保留一次禁止工具调用的结果总结。已保存草稿可在下一轮继续修订，不因本轮结束而丢失。

## 下载与更新

Windows x64 提供 `MoreThanChat-0.2.1-x64-setup.exe` 安装器、`MoreThanChat-0.2.1-win.zip` 压缩包和 `SHA256SUMS.txt`。更新前完全退出旧客户端（包括托盘），然后安装新版或解压至新目录运行；不要混用新旧目录中的文件。既有用户数据不清除。

中心服务协议未改变，现有 v0.2.0 中心服务器不必为此次客户端修复升级。默认地址仍是 localhost，云端地址在设置中手动配置。仍不包含自动更新、预装测试插件或 API 密钥；安装器暂未代码签名。

## 验收范围

本版增加默认契约、225 格源码保存、语法诊断、失败修订、旧格式兼容和 12 轮收尾的自动回归，并执行构建和 CI 检查。按用户要求，真实模型创作和从下载到运行的用户端验收由用户执行；本次没有调用真实 AI，也不声称这些自动测试证明任意模型必定生成正确游戏。
