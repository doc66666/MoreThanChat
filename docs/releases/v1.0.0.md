# MoreThanChat v1.0.0

这一版把应用内置功能与用户插件接入同一套运行机制，并加入消息渲染插件和一组可以直接使用的插件示例。

## 插件与热更新

- 内置界面、聊天控制器和后台服务支持由用户插件替换、包装、停用和热更新。
- 修复服务重绑、停用和重启后的状态衔接，保留聊天记录与用户的启停选择。
- 后台插件首次加载失败时也会出现在管理面板，可查看错误、修改后重新加载。
- 修复插件入口报错后，即使安装修正版仍停留在错误提示的问题。

## 消息与聊天

- 消息气泡、正文和附件可单独替换；支持自定义消息格式，发送端与接收端统一显示 Markdown。
- 新增 HTML 消息卡片，支持编辑、实时预览和发送。接收方未启用渲染插件时显示文字摘要，启用后可直接显示历史卡片。
- 格式正文随离线消息、本机历史和转发保留，引用、撤回、回执及未读行为继续生效。
- 编辑草稿按会话保存在本机，切换聊天、热更新和重启后可以继续编辑；支持 Ctrl / ⌘ + Enter 发送。
- 修复连续发送相同卡片被误判为重试的问题，真正的失败重试仍沿用原发送 ID。
- 时间线统一维护消息定位节点，替换整个气泡后仍可定位消息。
- 修复插件小窗遮挡聊天时仍被标为已读的问题。

## 可选示例与群聊分享

- 插件示例库提供常用短语、专注计时、翻牌记忆、一起井字棋和 HTML 消息卡片，按需添加。
- 示例可复制为独立草稿，交给内置 AI 继续修改，也可按普通插件流程停用、更新和卸载。
- 好友同意或群管理员批准后，成员可自行载入共享插件。井字棋支持实时对弈、观战和换人；消息渲染插件也可通过同一流程分享和使用。
- 内置 AI 的作者说明补充了消息渲染入口、自定义格式及聊天读写接口的用法。

## 下载与使用

- Windows 安装包：`MoreThanChat-1.0.0-x64-setup.exe`
- Windows 便携压缩包：`MoreThanChat-1.0.0-win.zip`
- Windows 中心服务器：`MoreThanChat-central-server-1.0.0-windows-x64.zip`
- Linux 中心服务器：`MoreThanChat-central-server-1.0.0-linux-x64.tar.gz`

中心服务器包自带运行环境、一键启动脚本和管理 CLI。Windows 运行 `start.cmd`，Linux 运行 `./start.sh`，配置、日志和黑白名单管理见包内 README。

使用 HTML 等扩展格式时，请同步升级中心服务器；普通文字和 Markdown 可继续连接旧版服务器。更新客户端前完全退出旧版本，无需删除聊天记录或插件。更新服务器时保留原配置、管理员凭据和数据目录。附件统一提供 `SHA256SUMS.txt` 校验文件。
