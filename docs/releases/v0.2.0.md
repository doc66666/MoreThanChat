# MoreThanChat v0.2.0 — 首个正式发行版

本次发布 Windows x64 客户端与可自行部署的中心服务器。原 v0.1.0 内测版及标签保留，不覆盖旧下载。

## 下载与运行

- `MoreThanChat-0.2.0-x64-setup.exe`：Windows 安装器，可选择安装位置。
- `MoreThanChat-0.2.0-win.zip`：完整客户端目录，解压后运行 `MoreThanChat.exe`，不要只复制 EXE。
- `MoreThanChat-0.2.0-central-server.zip`：纯代码服务端，适用于 Linux / Windows，要求 Node.js `>=24.12.0 <25`；解压后运行 `node server.mjs`。部署参数见包内 `OPERATIONS.md` 与 `deploy/` 模板。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

默认中心地址为 `http://localhost:8787`；没有由项目方运营的公共服务器。先启动本机中心服务，或在客户端设置中连接自建服务器。同一中心上的用户才能建立关系、聊天与同步插件。私服可使用白名单控制接入。

升级由用户自行下载执行，不包含自动更新服务。安装包不带测试账号、API 密钥、聊天数据库或预装演示插件；不删除用户已有配置和已安装插件。

## 已交付体验

- 好友与群聊、文字/表情/附件/语音、本机消息历史、搜索、引用、转发、撤回、送达与已读、持久发送队列及离线补投。
- 暖白陶橙白天主题、Tokyo Night Storm 夜间主题、跟随系统和通知/托盘设置。
- 接入兼容协议的 AI API，在聊天内通过工具创建、校验和修改插件草稿，再由用户安装。
- 同一个可执行界面插件可本机使用，也可申请分享至群聊或私聊：管理员或另一位好友同意后分发，每位成员自行选择载入本机。
- 共享插件通过作用域绑定的 `sdk.network` 接口发送、接收与补读事件；本机、不同群、不同私聊的实例相互隔离。
- Cordis 生命周期与热更新；插件可扩展、包装或替换整桌面，而非限制在固定九处插槽。

应用版本为 0.2.0；现有插件契约仍是 `engine.moreThanChat: ^0.1.0`。不要仅因应用版本变更而修改插件契约版本。多人插件的业务状态、持久化和升级迁移由插件作者负责，中心不提供插件业务状态存储服务。

## 验收与边界

本地已覆盖类型检查、单元测试、源代码与打包客户端回归；新增三端验收覆盖 AI 工具调用生成与修订、安装、群/私聊审批分发、成员载入、井字棋同步、换人、更新、停用和断线重连。AI 自动验收使用本地确定性模型响应，不等于对任意真实模型生成质量的保证。可在对应发布提交的 GitHub Actions 查看 Windows 与 Linux 检查结果。

当前安装器未代码签名，Windows 可能提示未知发布者。客户端可执行插件是用户选择运行的受信任代码，不是恶意代码沙箱。正式发行不代表完成公网大规模容量或长时间稳定性认证。Android 客户端与端到端加密尚未交付。服务端离线暂存与消息 ACK 清理不等于云端永久历史；历史主要保存在用户本机。
