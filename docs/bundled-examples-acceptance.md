# 可选插件示例验收（2026-11-08）

本轮在插件面板加入「插件示例库」：常用短语、专注计时、翻牌记忆、一起井字棋。默认不安装，选择后使用普通可执行客户端包的校验、摘要、Cordis 运行时、安装控制器与持久启停状态。没有新增专用游戏服务或自动回复业务。

「复制为草稿」生成独立 ID；已有安装时复制当前安装代码，内置 AI 可以通过既有作者工具读取并继续修改。示例库不会自动覆盖用户修改或重启后重新安装已卸载插件。使用说明和源码组织见 [可选示例说明](../examples/bundled/README.md)。

## 真实客户端

使用构建后的 Electron 客户端、三个隔离身份目录与本机中心服务器，关闭旧 QA 演示插件，沿实际界面操作验证：

- 空白身份没有自动安装示例，示例库四个入口都能安装，复制出的草稿校验通过。
- 自定义短语保存、追加到已有输入框，既不覆盖原文也不发送；重启仍保留。
- 专注计时关闭小窗后继续，聊天顶部显示剩余时间；重启后按截止时间恢复。
- 翻牌完成八组配对，记录最佳步数，重启保留纪录。
- 本机井字棋轮流操作、存档与重启恢复。
- 群内提交、管理员批准、成员自主载入；双端落子与胜负同步；第三位成员晚加入能观战；新一局清空席位，第三人可上场；重启收到离线期间的落子。
- 好友同意分享后使用相同源码联机；本机、好友与群聊状态隔离。
- 同 ID 草稿热更新后只有一个对应入口；示例库不覆盖新安装版本；Escape 关闭小窗；卸载移除界面贡献。
- 明暗主题实拍检查。

复查发现 HTML dialog 的 `open` 属性未被已读可见性观察器监听。新增回归测试先复现失败，再将该属性纳入观察。真实窗口保持聚焦并定位到最新消息时，打开示例小窗收到的新消息保持未读，关闭后恢复已读；没有通过停用滚动定位来解决遮挡问题。

`verify-composition-ui.mjs` 同时复核已有视图／服务替换、AI 流式回复中热更、后台首次失败的管理流程、停用重启恢复、离线补投及双向聊天，全部通过。
